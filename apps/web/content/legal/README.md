# Baked customer legal pack

These files are copies of the published 12 July 2026 documents in `docs/legal/`.
The web app renders them statically so `/legal/*` and `/dpa` do not depend on the API.

The refund/access note in this directory is the current private-beta commercial position:
waitlist, evaluation, and invite; no self-serve checkout this week. It is not a new contract.

Do not publish `rakshex-terms-of-service.docx` or `rakshex-refund-cancellation-policy.docx`
under `apps/web/public/legal`. Online `/terms` is the current contract.

Update `docs/legal/` first, then copy into this directory.
